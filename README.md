# Algovisi – Algorithm Visualization  

An interactive web tool to **visualize core algorithms** with animations and step-through controls. Algovisi is designed to help learners understand **data structures** and **algorithm flow** through engaging, intuitive visualizations.  

## 📖 Overview  
Learning algorithms can be challenging when relying solely on theory. **Algovisi** bridges the gap between abstract concepts and practical understanding by providing:  
- Real-time visualizations of algorithms in action.  
- Step-by-step controls to observe how each algorithm progresses.  
- An interactive interface built for students, educators, and anyone exploring computer science fundamentals.  

## ✨ Features  
- 🔄 **Step-through Controls** – Play, pause, and step through algorithm execution.  
- 🎨 **Animations** – Smooth visual feedback for sorting, searching, and graph algorithms.  
- 📚 **Multiple Algorithms** – Supports common algorithms (e.g., Bubble Sort, Merge Sort, DFS, BFS).  
- 🌐 **Web-based** – Runs directly in the browser, no extra installation needed.  

## 🛠️ Tech Stack  
- **React** – Front-end framework for building the interactive UI.  
- **JavaScript (ES6+)** – Core logic and animations.  
- **HTML & CSS** – Layout and styling.  
- **Git** – Version control for project management.
